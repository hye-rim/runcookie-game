# 달려라 쿠키 🍪

오븐에서 도망친 쿠키가 젤리를 먹으며 끝없이 달리는 러닝 게임. 의존성 없는 정적 게임(`index.html` + `game.js`)입니다.

- 점프(누른 시간만큼 높이, 한 번 더 누르면 2단 점프)와 슬라이드(누르고 있기)로 장애물을 피해요
- 체력이 계속 닳고, 물약을 먹어 채워요. 부스터는 장애물을 부수며 날아가고, 자석은 젤리를 끌어당겨요
- 400m마다 구역이 바뀌고(사탕 나라 → 초코 숲 → 별밤 정원), 갈수록 빨라져요
- 최고 점수는 localStorage `runcookieBest` 에 저장
- 조작: Space·↑ 점프, ↓ 슬라이드, P 일시정지, M 소리. 폰은 항상 가로 화면(세로로 들면 화면을 눕혀서 채움), 양쪽 끝 버튼으로 슬라이드/점프

`game.js` 위쪽 로직(`newWorld`, `stepWorld` …)은 DOM 없이 `require` 로 불러와 테스트할 수 있습니다.
